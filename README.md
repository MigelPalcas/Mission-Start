# Mission-Start

Acabas de ser contratado como Desarrollador Junior en NextGen Web Solutions. Tu primera misión no es escribir código desde cero, sino preparar tu "estación de combate" digital y resolver un problema de rendimiento que está afectando a un cliente importante.
Milestone 1 — Configuración del entorno de desarrollo
Issue 1 — Instalar Visual Studio Code

Descripción:
Instalar y preparar Visual Studio Code como editor principal para el desarrollo del proyecto.

Checklist

Descargar VS Code desde la página oficial

Instalar el editor en el sistema

Abrir el proyecto desde VS Code

Verificar que el editor funciona correctamente

Issue 2 — Instalar ESLint

Descripción:
Configurar ESLint para analizar el código JavaScript y detectar errores o malas prácticas durante el desarrollo.

Checklist

Instalar la extensión ESLint en VS Code

Activar ESLint en el proyecto

Verificar que detecta errores en archivos JavaScript

Issue 3 — Instalar Prettier

Descripción:
Configurar Prettier para mantener el código con un formato uniforme en todo el proyecto.

Checklist

Instalar la extensión Prettier en VS Code

Configurar Prettier como formateador predeterminado

Activar la opción format on save

🏁 Milestone 2 — Auditoría de rendimiento del sitio
Issue 4 — Revisar pestaña Network

Descripción:
Analizar las solicitudes de red del sitio web usando las herramientas de desarrollador del navegador.

Checklist

Abrir DevTools con F12

Ir a la pestaña Network

Recargar la página para capturar las solicitudes

Revisar tiempos de carga de los recursos

Issue 5 — Revisar errores en Console

Descripción:
Detectar errores de JavaScript que puedan afectar el funcionamiento del sitio.

Checklist

Abrir DevTools

Ir a la pestaña Console

Identificar errores o advertencias

Anotar los errores encontrados

Issue 6 — Identificar recursos pesados

Descripción:
Detectar archivos que estén ralentizando la carga del sitio web.

Checklist

Revisar tamaños de archivos en Network

Identificar imágenes o scripts grandes

Registrar recursos con tiempos de carga altos

Documentar posibles optimizaciones

🏁 Milestone 3 — Inicialización del proyecto
Issue 7 — Inicializar proyecto con npm

Descripción:
Crear la configuración inicial del proyecto utilizando npm para gestionar dependencias.

Checklist

Crear carpeta del proyecto

Ejecutar npm init -y

Verificar que se crea el archivo package.json

Issue 8 — Crear estructura del proyecto

Descripción:
Definir una estructura básica de carpetas para organizar el código del microservicio.

Checklist

Crear carpeta src

Crear archivo principal index.js

Organizar archivos del proyecto

Issue 9 — Inicializar repositorio con Git

Descripción:
Configurar el control de versiones utilizando Git.

Checklist

Ejecutar git init

Crear archivo .gitignore

Añadir archivos con git add .

Crear primer commit
